# Age Calculator

Next.js age calculator — also packaged as a **native Android app** with Capacitor.

## Web (Next.js)

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build   # static export → /out
npm run deploy  # GitHub Pages from /out
```

## Mobile (Capacitor)

See **[CAPACITOR.md](./CAPACITOR.md)** for the full step-by-step setup (what was done and how to run it).

Quick start (requires [Android Studio](https://developer.android.com/studio)):

```bash
npm install
npm run cap:android
```

Then press **Run** in Android Studio on an emulator or USB device.
